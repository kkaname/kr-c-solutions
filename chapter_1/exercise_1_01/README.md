# Exercise 1-1: Hello, World

**Question:** Run the ``hello, world'' program on your system. Experiment with leaving out parts of the program, to see what error messages you get. 

## Build & Run
### Compile:
```sh
gcc -o hello_world hello_world.c
```
### Run:
```sh
./hello_world
```

## Output:
```
hello, world
```
